# Guanwei's Website

> 2026 全新改版的個人網站。A new version of my personal website, rebuilt in 2026.

這個網站記錄我的專業經歷、系統整合能力、可公開專案與持續研究方向，內容涵蓋智慧工廠、製造與倉儲系統、全端軟體開發，以及 AI 相關研究。

## Technology

- React
- TypeScript
- Vite
- Oxlint

## Local Development

```bash
npm install
npm run dev
```

預設開發網址為 `http://localhost:5173`。

## Verification

```bash
npm run lint
npm run build
```
